Este simulador roda uma simulação de fluido 3D inteira na GPU. Em notebooks com duas GPUs, o navegador costuma abrir na integrada, que é bem mais fraca. No Windows, o Chrome e o Edge usam uma só GPU para o navegador inteiro e uma página não consegue pedir a dedicada: é preciso configurar uma vez no navegador ou no Windows.

Verificando a GPU…
1

Pela flag do navegador mais rápido

  1. Copie este endereço
  2. Cole na barra de endereço de uma aba nova e aperte Enter.
  3. Em Force high-performance GPU, troque Default por Enabled.
  4. Clique em Relaunch (reiniciar), no canto inferior da página.
2

Pelas configurações de gráficos do Windows

  1. Aperte Win + I e vá em Sistema → Tela → Elementos gráficos.
  2. Procure na lista. Se não estiver lá, clique em Procurar e escolha o executável:
  3. Clique no navegador, abra as Opções e escolha Alto desempenho (a placa NVIDIA ou AMD aparece pelo nome). Salve.
  4. Feche todas as janelas do navegador e abra de novo.
3

Pelo painel da placa (alternativa)

NVIDIA: botão direito na área de trabalho → Painel de controle da NVIDIA → Gerenciar as configurações 3D → Configurações de programa → escolha o navegador → Processador NVIDIA de alto desempenho → Aplicar.

AMD: AMD Software → Gráficos (ou Sistema → Gráficos alternáveis) → escolha o navegador → Alto desempenho.

Ainda não funcionou?
  • Confira se a aceleração por hardware está ligada: → Usar aceleração gráfica quando disponível.
  • Notebook: ligue na tomada e desligue o modo de economia de energia, que pode prender a placa dedicada.
  • Atualize o driver da placa de vídeo (NVIDIA App / AMD Software).
  • Para ver o que o navegador detectou, abra .
  • Sem WebGPU? Use Chrome ou Edge atualizados.
  • macOS escolhe a GPU sozinho; em celulares não há o que configurar.
Depois de reiniciar o navegador, volte aqui: o ponto do botão GPU fica verde e o nome da placa aparece no canto superior direito.
